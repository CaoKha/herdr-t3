# 重写决策（2026-11-14 用户拍板）

依据同目录 6 份审查报告。凡报告里标「（建议）」的决策点，除下面注明的例外，一律按建议执行。

## 顺序

共享控件 → 面板 → Details → Files → 子 agent，串行在 `main` 上做；壁纸在独立 worktree 并行，最后 rebase 回 `main` 再 sync。研究证据清理放在推送前最后做。

## 各块决定

- **共享控件**（`shared-controls.md`）：4 点全按建议。Details split 静止时照 T3 显示箭头，删掉 `quiet`；窄页面包屑多级菜单接受部分遮挡，并如实写进文档；子 agent 列表也改成指针离开就熄灭；Details/Files 的像素值移出 RECIPE，只留在 `t3-tokens.md`。
- **面板**（`panel-surfaces.md`）：
  - 同名文件标签**和 T3 一样不区分**（不按建议），文档和测试里的「相对路径提示」改成与此一致。
  - 横滚箭头按 T3 并排放右侧、到头禁用；`cmd-t`/`cmd-w` 只走 `keys.json` 的 `mod:` 分区（实施时改定：宿主先把按键交给绑定还是先交给视图没有文档、也无法不抢焦点地验证；若先给绑定，只留 `on_key_down` 会让 `cmd-w` 关掉终端标签。`mod:` 分区在两种顺序下都只触发一次，同样满足「只留一条路、不重复触发」）；关闭后释放由各 mod 通过 born 自己负责；切标签用每个标签一个 reveal 计数；「Review 是否可用」合成一个共享函数；Review 读哪个仓库统一为当前标签最后活动终端的 cwd，没有时回退 space 文件夹（用户点验发现 space 文件夹不是仓库时 + 菜单误报不可用）。
  - 旧的固定 Files/Review 页自动迁移**删除**。
- **Details**（`details-popup.md`）：5 点全按建议。Quick Review 子层改为独立原生 popup 级联；删掉范围快照缓存；文案改用 GLOSSARY 用词；来源规则与 Details 统一；Review 还没显示过范围时，范围菜单不打勾。
- **Files**（`files-panel.md`）：
  - 菜单改为原生 popup 加级联，Open in 选择器与 Details 共用一份。
  - 搜索用子串过滤加纯函数排序：文件名命中优先，其次路径短的靠前。
  - 只有用户从树或面包屑发起时才聚焦树。
  - 删除多选，保持窗口在前才读取。
  - Review 的树也改用 Pierre 图标，删除 Catppuccin 图标包。
- **子 agent 菜单**（`sub-agent-menu.md`）：4 点全按建议。圆点只表示没看过的完成；弹层里不要折叠；Failed 与 Needs you 共用 `!` 徽章，只换文字和颜色；标题栏恢复父 agent 自己的状态。
- **壁纸**（`wallpaper.md`）：
  - 保存后的壁纸也改用合成图，两条渲染路径合成一条。
  - Studio 指引改为独立弹层，去掉禁用的占位按钮。
  - 保留重新取景，修掉错误提示和重复转换。
- **研究证据**：只留各目录的 README 结论和复现所需脚本。推送前改写本地未推送的历史，彻底去掉大文件（PNG/JPG/原始 json/jsonl/日志）。

## 设计（依据 design-audit.md，2026-11-14 用户拍板）

- 9 条设计原则全部采纳，写进 `t3-tokens.md` 的「规则」一节，以后每块重写都按它自查。
- 面板列的左右边距统一为面板内 12，包括面板头、Files 头部和 Review 顶栏。
- 同一条 40px 顶栏上的按钮，悬停和按下的底色都用 `chrome`；Details 和面板开关从 `card` 改过来。
- 壁纸预览卡从上往下依次是标题、名字、模式、取景、按钮。
- 打开弹层的按钮全部照侧栏 Filter by space 的做法（原则 P6），由共享控件负责人做成一个共享的触发按钮后统一迁移。
- 两棵树统一：Files 和 Review 都用 `shared/file-tree.js` 的 `treeRow`，行的样子不随插槽变化；去掉折叠箭头，用文件夹图标的开合两态表示展开；图标统一用 Pierre，缩进线、行高、间距和悬停也统一。
- 成组按钮的间距和对齐：用户最终定为照侧栏头的做法：同组按钮相接，不留间距，也就是 design-audit.md 第五节的方案 C。全窗口同组图标按钮间距 0、节距 28；组与组之间、按钮与文字或输入框之间仍留 8。侧栏头保持现状，Search 框不变；工作区右上角、面板头、Files 头部、Review 顶栏都改成相接。和 T3 的 PanelLayoutControls、DiffPanel 等处的 gap-1 不同，写进 t3-tokens 的「有意不同」。原则 P3 相应改成「同组相接，组间 8」。对齐规则：R1 每条顶栏最右的按钮，右缘对齐正下方那一行最右的控件；R2 同一列的按钮尺寸相同（Review 顶栏、Lists 里的 + 都改成 28）；R3 侧栏卡片和 slim 行的左右内边距从 10 改成 8。
